# Fase 6 — i18n + pulido UX — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Internacionalizar la UI (gettext con español como primer idioma objetivo) y pulir la UX (tooltips y aceleradores de teclado).

**Architecture:** glib's `gi18n.h` (`_()` con `GETTEXT_PACKAGE`), dominio "tg", catálogo `po/es.po` compilado a `.mo` con `msgfmt` e instalado en `$(localedir)/es/LC_MESSAGES/`. Marcado de strings en interface.c, output_panel.c y watch_panel.c (solo cadenas visibles al usuario; las unidades técnicas s/d, ms, deg, bph quedan sin traducir). UX: tooltips en los controles principales y aceleradores de teclado.

**Tech Stack:** gettext, GTK3, autotools.

**Rama:** `feature/i18n-ux` (creada desde `master`).

---

### Task 1: Infraestructura gettext

- [ ] `configure.ac`: tras SQLITE:
```m4
GETTEXT_PACKAGE=tg
AC_SUBST(GETTEXT_PACKAGE)
AC_DEFINE_UNQUOTED([GETTEXT_PACKAGE], ["$GETTEXT_PACKAGE"], [translation domain])
LOCALEDIR=[${datadir}/locale]
AC_SUBST(LOCALEDIR)
```
- [ ] `src/interface.c` `main()` — tras `gtk_disable_setlocale();`:
```c
	bindtextdomain(GETTEXT_PACKAGE, LOCALEDIR);
	bind_textdomain_codeset(GETTEXT_PACKAGE, "UTF-8");
	textdomain(GETTEXT_PACKAGE);
```
  con `#include <glib/gi18n.h>` en los tres archivos UI (interface.c, output_panel.c, watch_panel.c) y en tg.h definir `_()` ya viene de gi18n.
- [ ] `Makefile.am`: reglas para compilar e instalar el catálogo:
```make
po/es.gmo: po/es.po
	msgfmt -o $@ $<

po_files = po/es.po
po_MOFILES = po/es.gmo

all-local: $(po_MOFILES)

install-data-local:
	mkdir -p $(DESTDIR)$(LOCALEDIR)/es/LC_MESSAGES
	$(INSTALL_DATA) po/es.gmo $(DESTDIR)$(LOCALEDIR)/es/LC_MESSAGES/tg.mo
```
- [ ] `.gitignore`: `/po/*.gmo`.
