# Fase 3-resto — Auto-gain + SNR — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajuste automático del nivel de entrada (botón "Auto" que calcula el gain para dejar el pico en ~0.8 sin CLIP) y SNR del tic en dB visible en el panel.

**Architecture:** `audio.c` añade `get_audio_gain()` (leer el gain actual) y `audio_suggest_gain(target)` (mide el pico reciente con `get_audio_level` y devuelve el gain sugerido = gain × target/peak, acotado 0.1–100). `interface.c` añade el botón "Auto" junto al spin de gain. Para el SNR: `compute_amplitude` (algo.c) ya estima el nivel de ruido frente al máximo global — se guarda `p->snr_db = 20·log10(glob_max/ruido)` y se propaga al snapshot para mostrarlo en un label junto al medidor de nivel.

**Tech Stack:** C99, GTK3, PortAudio.

**Rama:** `feature/auto-gain` (creada desde `master`).

- [ ] `src/audio.c` (tras `set_audio_gain`):

```c
double get_audio_gain(void)
{
	double g;
	pthread_mutex_lock(&audio_mutex);
	g = audio_gain;
	pthread_mutex_unlock(&audio_mutex);
	return g;
}

/* Sugiere el gain para llevar el pico reciente a `target` (0-1). */
double audio_suggest_gain(double target)
{
	float peak = 0;
	double g = get_audio_gain();
	get_audio_level(&peak, NULL);
	if(peak <= 0.001) return g;   /* sin señal: no sugerir cambios */
	double suggested = g * (target / peak);
	if(suggested < 0.1) suggested = 0.1;
	if(suggested > 100.0) suggested = 100.0;
	return suggested;
}
```

```c
static void handle_auto_gain(GtkButton *b, struct main_window *w)
{
	UNUSED(b);
	double ng = audio_suggest_gain(0.8);
	ng = round(ng * 10) / 10;   /* el spin muestra 1 decimal */
	if(ng < 0.1) ng = 0.1;
	if(ng > 100.0) ng = 100.0;
	w->gain = ng;
	set_audio_gain(ng);
	gtk_spin_button_set_value(GTK_SPIN_BUTTON(w->gain_spin_button), ng);
}
```

## Interpretación SNR
- > 20 dB: medición fiable.
- 10–20 dB: regular — revisa posición/nivel.
- < 10 dB: señal pobre (ruido dominante).
